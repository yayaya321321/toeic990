🔥 Firebase 設定指南

1
前往 console.firebase.google.com，點「新增專案」，輸入專案名稱（如 toeic990），關閉 Google Analytics，建立專案。
2
進入專案後，點左側「Authentication」→「開始使用」→「Sign-in method」→ 啟用 Google 登入。
3
點左側「Firestore Database」→「建立資料庫」→ 選「以測試模式開始」→ 選伺服器位置（asia-east1 最快）。
4
點左上齒輪「專案設定」→ 向下滾找「您的應用程式」→ 點「</>」網頁圖示 → 輸入應用程式暱稱 → 複製 firebaseConfig 的內容。
5
用文字編輯器（記事本）開啟這個 HTML 檔，找到 YOUR_API_KEY 等欄位，貼上你的設定值，儲存。
6
在 Firebase Console → Authentication → Settings → 授權網域，加入你存放這個 HTML 的網域（或用 GitHub Pages 免費托管）。
💡 完全免費方案：Firebase 免費額度每天 50,000 次讀取、20,000 次寫入，個人學習完全夠用。托管推薦用 GitHub Pages（免費），把 HTML 上傳到 GitHub repo 即可。
